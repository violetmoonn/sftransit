Publishing the SFtransit update — 3 steps on github.com/violetmoonn/sftransit

STEP 1 — Upload
  • Click "Add file" → "Upload files".
  • Open the folder "STEP 1 - drag these into GitHub", select EVERYTHING inside it
    (Cmd+A), and drag it onto the GitHub page.
    (Drag the contents, not the STEP 1 folder itself.)
  • Wait until the file list stops growing, then click "Commit changes".

STEP 2 — Scheduled alert check
  • Click "Add file" → "Create new file".
  • In the name box type exactly:  .github/workflows/transit-alerts.yml
  • Open "STEP 2 - paste this into a new file.txt", copy all of it (Cmd+A, Cmd+C),
    paste it into the big box on GitHub, then click "Commit changes".

STEP 3 — Clean up
  • Follow "STEP 3 - delete these on GitHub.txt".

Vercel updates sf-transit.com about a minute after each commit.
